# NaturoForumSMP Mod

Client-side Fabric mod for the NaturoForumSMP server. It equips your elytra automatically when you jump off a ledge and swaps your chestplate back when you land.

Some servers consider automatic elytra swapping cheating. Check the rules of the server you play on.
